# Radar de Casos de Uso de IA

Mural da turma: um formulário grava casos de uso no schema `radar` do Supabase e a página lista os registros do mais recente para o mais antigo.

## Ambiente

Crie `.env.local` (não versionar):

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Use a chave anon. Não use a chave service_role.

```bash
npm install
npm run dev
```

Abra http://localhost:3000
